# TenderBot - Автоматизация тендерных закупок

Telegram-бот для автоматической обработки тендерной документации, поиска товаров и генерации коммерческих предложений.

## Возможности

- 📤 Загрузка и парсинг ZIP-архивов с тендерной документацией
- 🤖 Извлечение номенклатуры через YandexGPT
- 🔍 Автоматический поиск моделей товаров в интернете
- 👥 Управление базой поставщиков
- 💼 Генерация коммерческих предложений с наценкой
- 📊 Экспорт в Excel, Word, PDF
